Akkity 1.0.0 brings a tiny offline AI companion to your Windows desktop.

- Complete Windows x64 installer with Gemma 3 1B and its CPU runtime included.
- Interpolated animation, walking, jumping, waving and configurable idle antics.
- Small comic chat bubble, local file attachments, summaries, checklists, search and export.
- Local chat history and configurable gestures, font and bubble dimensions.
- Tray reopening, Ctrl+Alt+A, and Start menu/desktop shortcuts.
- Virtual treats, playtime, quiet nap mode and local care counters.
- Focus timer and fully offline replies after download.

Download **Akkity-Setup.exe**, open it, accept the included model terms, and install. No Python, API key, account or separate model setup is needed. Windows 10/11 x64; 8 GB RAM recommended, 2 GB free disk space.

This is an unsigned community build. Windows may display an unknown-publisher warning. Compare the downloaded file against SHA256SUMS.txt. Gemma is a small model and may make mistakes. Images/scanned PDFs and computer-control actions are unsupported.

Validated on Windows 11: real local Gemma reply, animation assets, three bubble sizes, fresh chats, hide/reopen, and text/DOCX/PDF extraction. Windows 10 has not been separately tested.
